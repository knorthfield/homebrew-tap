# knorthfield/tap

Homebrew casks for my apps.

```sh
brew install --cask knorthfield/tap/stenographer
brew install --cask knorthfield/tap/clerk
brew install --cask knorthfield/tap/nightwatchman
brew install --cask knorthfield/tap/napkin
```

| Cask | App |
| --- | --- |
| `stenographer` | [Stenographer](https://github.com/knorthfield/stenographer): menu bar dictation. Hold right Option, speak, release. |
| `clerk` | [Clerk](https://github.com/knorthfield/clerk): meeting note taker and coach. Live transcript, speakers, talking points and markdown notes. |
| `nightwatchman` | [Night Watchman](https://github.com/knorthfield/nightwatchman): keeps your Mac awake from the menu bar, also when the lid is closed. |
| `napkin` | [Napkin](https://github.com/knorthfield/napkin): a calculator in a notepad. Write calculations in numbers and words. |
